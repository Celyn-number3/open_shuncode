# 0.7.10 永久默认权限

按用户明确要求替代 0.7.9 的默认只读、15 分钟授权：

- 默认整机模式；终端和自定义工具均开启。
- 所有授权不按时间或闲置过期；重连和重载采用同一持久默认。
- 新命令：`ShunCode: 设置 MCP 永久默认权限`。
- 可以调整单个会话；撤销全部会把持久默认也改为只读，防止重连立即重获权限。
- 内置文件工具仍限工作区。终端、自定义工具可操作账号有权访问的其他文件，不是沙箱。
- 拥有有效连接凭据的现代无状态客户端也获得统一默认权限，自报标识不构成个人身份隔离。

Linux 本地自动回归 35 项通过；Windows、云端 CI、源码及发行编辑器烟测与 ZIP 校验由交付阶段实际执行，最终结果单独记录。旧 0.7.8 Release、0.7.9 验证包和历史报告不覆盖。不自动重载当前维护连接。完整源码缺失的限制没有改变。
