## 未完成，不能声称“全部完成”

1. 完整源码构建仍缺少 27 个共享模块、工作台定制和运行时源码。现有公开上游接口未能取得这些内容。本轮明确使用基线增量构建，没有伪造缺失实现。
2. 没有新增内核级终端沙箱。项目模式关闭任意终端；用户授予整机权限后仍可访问本机账号有权访问的其他文件。
3. 全部人工授权确认操作、模型 API 调用、多模型合并和公网隧道故障恢复未做全量 GUI 回归，不能以激活烟雾测试代替。
4. 当前维护实例仍运行原来已加载的代码。重载编辑器后新连接才使用新权限模型；本轮没有自动中断该连接。

## 使用与后续

重载后，在命令面板选择 `ShunCode: 管理 MCP 会话权限`。默认只读；需要修改时选项目权限，需要任意命令时明确选择高风险整机权限。不应把终端授权当作工作区隔离。

继续完成完整源码构建需要取得对应的上游共享模块、运行时和工作台源码。完整终端隔离需要容器、虚拟机或受限账号设计，不能用命令字符串白名单冒充。
