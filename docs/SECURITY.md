# 安全边界（0.7.10 个人高强度使用配置）

本版本按用户明确要求，默认整机模式，终端与自定义工具开启，授权没有时间或闲置过期。此默认适用于所有拥有有效连接凭据的客户端，包括现代无状态客户端；不再提供默认只读保护，也不把客户端自报标识当作认证身份。

## 保留的检查

- 真实执行前统一检查当前权限，包括排队之后的检查；客户端工具参数不能改变授权。
- 内置文件和补丁工具仍核对工作区真实路径，拒绝目录穿越、symlink/junction 越界；过期补丁版本保护保留。
- 标准名称检查、防别名混淆、权限敏感工具列表私有缓存、日志脱敏及有限摘要审计仍保留。
- 默认只读配置下，无状态客户端不能单独取得提升权限；只有本机统一选定的默认能力可不依赖会话绑定使用。

## 永久默认与手动控制

`ShunCode: 设置 MCP 永久默认权限` 将默认保存到编辑器全局状态并立即应用。`管理 MCP 会话权限` 调整单个现有连接，不改变新连接默认。

`撤销全部 MCP 会话权限` 同时将持久默认改为只读，并请求中止相关执行；新连接也保持只读，直到本机重新开启。单纯断开连接不是封禁，重新连接按持久默认恢复。编辑器本身或协议可以重建连接，但不会出现权限每 15 分钟到期的提示。

## 不能保证的事项

整机终端与自定义工具可能修改工作区外文件、访问网络或发送数据。只能受当前 Windows 账号权限约束，不自动获得管理员权限，不是操作系统沙箱。自定义工具即使不启用内置终端也可能自行执行命令。撤销请求不保证所有子进程或忽略取消信号的工具立即停止，也不能撤回已写入或发送的数据。

MCP URL、访问 token 和会话凭据必须保密。日志脱敏不等于任意秘密检测；工作区也可能包含敏感文件。完整源码仍缺共享模块、工作台及运行时源码，使用已检查的遗留基线增量构建，不能宣称已完成完整源码编译。
